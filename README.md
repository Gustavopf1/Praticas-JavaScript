# Praticas-JavaScript

Este repositório é destinado às minhas práticas de JavaScript, com o objetivo de desenvolver minhas habilidades na linguagem e entender melhor alguns conceitos, como: `Arrow Functions`, `Export` e `Import`, `push()`, `find()`, `findIndex()`, `splice()`, `filter()`, `map()`, `reduce()`, `async/await`, `Promise`, `Callback`, `setTimeout()`, `readline`.
